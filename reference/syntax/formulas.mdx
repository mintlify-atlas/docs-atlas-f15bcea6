## Overview

Formulas allow you to execute JavaScript expressions within your templates to perform calculations, transformations, and complex logic.

## Formula Syntax

Formulas are enclosed in `{{% %}}` and must start with `return`:

```markdown
{{% return expression %}}
```

<Note>
All formula expressions must begin with the `return` keyword.
</Note>

## Basic Calculations

Perform arithmetic operations on your data:

```markdown
{{% return value1 + value2 %}}
{{% return amount * 1.1 %}}
{{% return total - discount %}}
```

### Example: Simple Calculation

<CodeGroup>
```json Data
{
  "$class": "hello@1.0.0.HelloWorld",
  "name": "John Doe"
}
```

```markdown Template
### Welcome {{name}}!

Your name has {{% return name.length %}} characters.
```

```text Output
### Welcome John Doe!

Your name has 8 characters.
```
</CodeGroup>

## Financial Calculations

Formulas are perfect for computing taxes, totals, and other financial values:

### VAT and Total Calculation

<CodeGroup>
```json Data
{
  "$class": "payment@1.0.0.PaymentReceipt",
  "amount": 250.00,
  "currency": "USD",
  "vatPercent": 10
}
```

```markdown Template
### Payment Summary

- Amount: {{amount as "0,0.00"}} {{currency}}
- VAT ({{vatPercent}}%): {{% return (amount * vatPercent / 100).toFixed(2) %}} {{currency}}
- Total Paid: **{{% return (amount + (amount * vatPercent / 100)).toFixed(2) %}} {{currency}}**
```

```text Output
### Payment Summary

- Amount: 250.00 USD
- VAT (10%): 25.00 USD
- Total Paid: **275.00 USD**
```
</CodeGroup>

## Date and Time

### The `now` Variable

Access the current date and time using the implicit `now` variable:

```markdown
{{% return now.toISOString() %}}
```

<CodeGroup>
```markdown Template
Today is **{{% return now.toISOString() %}}**.
```

```text Output
Today is **2024-06-15T10:30:00.000Z**.
```
</CodeGroup>

### Date Methods

<Tabs>
  <Tab title="ISO String">
    ```markdown
    {{% return now.toISOString() %}}
    ```
    Output: `2024-06-15T10:30:00.000Z`
  </Tab>
  <Tab title="Date String">
    ```markdown
    {{% return now.toDateString() %}}
    ```
    Output: `Sat Jun 15 2024`
  </Tab>
  <Tab title="Year">
    ```markdown
    {{% return now.getFullYear() %}}
    ```
    Output: `2024`
  </Tab>
  <Tab title="Month">
    ```markdown
    {{% return now.getMonth() + 1 %}}
    ```
    Output: `6` (January is 0)
  </Tab>
</Tabs>


## Complex Calculations

Combine multiple operations for sophisticated logic:

### Multi-tier Discount Calculation

```markdown
{{% return amount > 1000 ? amount * 0.85 : amount > 500 ? amount * 0.90 : amount * 0.95 %}}
```

### Percentage Calculation

```markdown
Progress: {{% return Math.round((completed / total) * 100) %}}}%
```

### Duration Calculation

```markdown
{{% return Math.floor(durationInMonths / 12) %}}} years and {{% return durationInMonths % 12 %}}} months
```

## Best Practices

<AccordionGroup>
  <Accordion icon="return" title="Always use return keyword">
    Formula expressions must start with `return`:
    
    ```markdown
    Good: {{% return amount * 1.1 %}}
    Bad: {{% amount * 1.1 %}}
    ```
  </Accordion>
  
  <Accordion icon="calculator" title="Format calculated numbers">
    Use `.toFixed()` for consistent decimal places:
    
    ```markdown
    {{% return (price * quantity).toFixed(2) %}}
    ```
  </Accordion>
  
  <Accordion icon="shield-check" title="Handle undefined values">
    Check for undefined before calculations:
    
    ```markdown
    {{% return discount ? (amount * discount / 100).toFixed(2) : '0.00' %}}
    ```
  </Accordion>
  
  <Accordion icon="code" title="Keep formulas readable">
    Break complex calculations into multiple formulas:
    
    ```markdown
    Good:
    - Subtotal: {{% return amount.toFixed(2) %}}
    - VAT: {{% return (amount * 0.1).toFixed(2) %}}
    - Total: {{% return (amount * 1.1).toFixed(2) %}}
    
    Avoid:
    - Total: {{% return (amount + (amount * vatRate / 100) + (amount * serviceFee / 100) - discount).toFixed(2) %}}
    ```
  </Accordion>
</AccordionGroup>

<Warning>
**Division by zero**

Always check for zero before division:

```markdown
{{% return total > 0 ? (completed / total * 100).toFixed(1) : 0 %}}%
```
</Warning>

<Tip>
**Reuse variable formatting**

For simple variable output, use the `as` formatter instead of formulas:

```markdown
Preferred: {{amount as "0,0.00"}}
Also works: {{% return amount.toFixed(2) %}}
```
</Tip>
